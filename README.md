# Escritorio Rubén

Web con todo lo que compro para el despacho: imágenes de cómo quedará, cada producto con su enlace y su porqué, el total, el plano del cuarto, cómo se conecta todo y los pendientes.

- Datos: `src/data/compra.ts` (precios del 17-18/10/2026).
- Imágenes del escritorio: `src/assets/render/` (generadas con Higgsfield a partir de las fotos del cuarto).
- Publicar: `npm run build && npm run deploy` (rama `gh-pages`).
